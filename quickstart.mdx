title: Quickstart

This guide walks you through cloning the repository, installing dependencies, and starting the development server. By the end, you will have a fully functional ElectroHome instance running at `http://127.0.0.1:8000`.

## Prerequisites

Before you begin, make sure you have the following installed:

- **Python 3.10+** — [python.org/downloads](https://www.python.org/downloads/)
- **pip** — included with Python 3.4 and later
- **Git** — [git-scm.com](https://git-scm.com/)

<Tip>
  Run `python --version` and `git --version` in your terminal to confirm both are available before proceeding.
</Tip>

## Set up ElectroHome locally

<Steps>
  <Step title="Clone the repository">
    Clone the ElectroHome repository from GitHub:

    ```bash
    git clone https://github.com/alan1130co/ecommerce-electrohome
    cd ecommerce-electrohome
    ```
  </Step>

  <Step title="Create a virtual environment">
    Create an isolated Python environment for the project to avoid conflicts with other packages on your system.

    <CodeGroup>

    ```bash macOS / Linux
    python3 -m venv venv
    source venv/bin/activate
    ```

    ```bash Windows
    python -m venv venv
    venv\Scripts\activate
    ```

    </CodeGroup>

    Once activated, your terminal prompt will show `(venv)` at the start.

    <Tip>
      To deactivate the virtual environment at any time, run `deactivate`.
    </Tip>
  </Step>

  <Step title="Install dependencies">
    Install all required Python packages:

    ```bash
    pip install -r requirements.txt
    ```

    This installs Django 5.2 and all project dependencies, including packages for authentication, payments, and media storage.
  </Step>

  <Step title="Set up environment variables">
    ElectroHome uses environment variables for secrets and third-party service credentials. Create a `.env` file in the project root:

    ```bash
    cp .env.example .env
    ```

    For local development with the default `electrohome/settings.py`, the minimum required variables are:

    ```bash .env
    SECRET_KEY=your-local-development-secret-key
    DEBUG=True
    ```

    <Note>
      For local development, ElectroHome uses SQLite by default — no database setup is required. Production integrations such as Cloudinary, Wompi, and Google OAuth are only needed for production deployments. See the [environment variables guide](/configuration/environment-variables) for the full list.
    </Note>
  </Step>

  <Step title="Run database migrations">
    Apply the database migrations to set up the SQLite schema:

    ```bash
    python manage.py migrate
    ```

    Django will create a `db.sqlite3` file in the project root and apply all migrations from installed apps including `django.contrib.admin`, `auth`, `contenttypes`, `sessions`, `messages`, and `staticfiles`.
  </Step>

  <Step title="Create a superuser">
    Create an admin account so you can log in to the Django admin panel:

    ```bash
    python manage.py createsuperuser
    ```

    You will be prompted to enter a username, email address, and password. Choose a strong password — Django will warn you if the password is too common or too short.

    ```
    Username: admin
    Email address: admin@example.com
    Password:
    Password (again):
    Superuser created successfully.
    ```
  </Step>

  <Step title="Start the development server">
    Start the Django development server:

    ```bash
    python manage.py runserver
    ```

    You should see output like this:

    ```
    Watching for file changes with StatReloader
    Performing system checks...

    System check identified no issues (0 silenced).
    Django version 5.2, using settings 'electrohome.settings'
    Starting development server at http://127.0.0.1:8000/
    Quit the server with CONTROL-C.
    ```

    <Note>
      The development server reloads automatically when you change Python files. You do not need to restart it during development.
    </Note>
  </Step>

  <Step title="Access the application">
    Open your browser and navigate to:

    | URL | Description |
    |-----|-------------|
    | `http://127.0.0.1:8000/` | ElectroHome storefront |
    | `http://127.0.0.1:8000/admin/` | Django admin panel |

    Log in to the admin panel at `http://127.0.0.1:8000/admin/` using the superuser credentials you created in the previous step.

    From the **Django administration** dashboard you can manage products, orders, users, and site configuration.
  </Step>
</Steps>

## What you have running

Your local ElectroHome instance uses:

- **SQLite** as the database (stored in `db.sqlite3`)
- **`DEBUG=True`** for detailed error pages
- **Local file storage** for media (no Cloudinary needed)
- **Django's built-in static file server**

<Warning>
  Never run with `DEBUG=True` in production. The development settings are intentionally insecure and expose detailed error information.
</Warning>
