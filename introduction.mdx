# Welcome to ElectroHome

ElectroHome is a full-featured e-commerce platform built with Django, designed for selling electronics and home appliances. It provides a complete online shopping experience with secure payments, user authentication, and cloud-based media management.

## What is ElectroHome?

ElectroHome is a production-ready Django e-commerce application deployed at [ecommerce-electrohome-render.onrender.com](https://ecommerce-electrohome-render.onrender.com). It is built for retailers who need a reliable, scalable online store for electronics and home appliances.

## Tech stack

| Layer | Technology |
|-------|-----------|
| Backend framework | Django 5.2 |
| Database | PostgreSQL (production), SQLite (development) |
| Authentication | django-allauth with Google OAuth |
| Payments | Wompi payment gateway |
| Media storage | Cloudinary |
| Static files | WhiteNoise |
| Deployment | Render |
